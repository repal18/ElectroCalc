# ⚡ ElectroCalc

### Interactive Electrical Calculator
**Developed by Kiagus Muhammad Revaldo**

ElectroCalc is an interactive web-based electrical calculator designed to support electrical engineering learning through practical calculations, circuit analysis, and electrical energy estimation.

Developed as an independent project, ElectroCalc combines fundamental electrical engineering concepts with web technologies to provide an accessible and interactive calculation platform.

## Features

### 1. Ohm's Law Calculator
Calculate electrical current, voltage, resistance, and power using fundamental electrical relationships.

### 2. Resistor Analysis
Analyze series and parallel resistor circuits, including equivalent resistance, total current, and individual circuit values.

### 3. Electrical Energy & Cost Calculator
Estimate daily and accumulated electrical energy consumption, as well as electricity costs based on equipment power, operating duration, quantity, and electricity tariff.

### 4. Kirchhoff's Current Law (KCL)
Calculate unknown current values using the relationship between total incoming and outgoing currents at a circuit junction.

### 5. Kirchhoff's Voltage Law (KVL)
Analyze voltage distribution in a single-loop circuit and verify the voltage balance around the loop.

### 6. Two-Loop Mesh Analysis
Calculate mesh currents and shared branch current in a two-loop resistive circuit using simultaneous equations.

### 7. Image Workspace
Upload, preview, and organize visual references directly within the browser session.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## How to Use

1. Open the ElectroCalc website through a web browser.
2. Select the calculation module you want to use.
3. Enter the required electrical parameters.
4. Run the calculation.
5. Review the results, formulas, and calculation details displayed by the application.

## Project Purpose

ElectroCalc was developed as a personal learning project to explore the integration of electrical engineering concepts and web development. It represents an effort to transform fundamental electrical calculations into an accessible digital tool while continuously improving technical knowledge and programming skills.
